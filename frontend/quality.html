Opções de preparação

No primeiro preparo, os modelos locais das descrições (Qwen Omni-7B, ~22,4 GB) e das letras (Whisper large-v3, ~3,1 GB) também são baixados. Downloads existentes são reaproveitados.

Monte o dataset de preferências

Use um manifesto com candidatos e avaliações, ou uma pasta de áudios com seus metadados.

MRSD mantém pares que melhoram conjuntamente os critérios. As avaliações devem pertencer aos mesmos candidatos e grupos do manifesto.

Opções de seleção dos pares

As opções JSON são enviadas ao construtor de pares. Consulte a configuração do dataset para os critérios e margens.

Avaliar candidatos · modelo ou avaliações manuais

CLAP avalia alinhamento à descrição; Audiobox avalia produção. Eles não certificam a letra ou clareza vocal. O eixo de consistência musical do artigo exige um checkpoint musical HuBERT compatível ou avaliações externas/manuais.

    Para usar duas GPUs, ative Multi GPU em Dispositivo e memória e informe GPU IDs: 0,1. Cada placa processa seu próprio microbatch; lote efetivo = batch size × gradient accumulation × número de GPUs. A memória das placas não é somada.
